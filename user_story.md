# User Story: Notes Management API

**Story ID:** NOTE-101

**User Story:**

As a user, I want to create, view, update, and delete notes so that I can keep track of important information.

**Requirements:**

- Create a note with a title and content.
- View all saved notes.
- View a note by ID.
- Update an existing note.
- Delete a note.
- Return an error when a note does not exist.

**Acceptance Criteria:**

- All CRUD operations work correctly.
- Invalid inputs are handled properly.
- Automated tests pass.
- README includes setup and usage instructions.
